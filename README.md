# Silicon to IC (Interactive Educational Module)

**Live Demo:** https://jeyaamantha.github.io/Silicon-to-IC-/  
**Platform:** Web (GitHub Pages)  
**Language:** English with technical terminology related to semiconductor fabrication  
**Development Tool:** Articulate Storyline

---

## Overview
**Silicon to IC** is an interactive learning module that guides users through the journey of transforming raw silicon into a functional integrated circuit (IC).  
Using visuals, animations, and structured interactions, this module provides an engaging and accessible way to explore semiconductor fabrication processes.

The content is presented in English and is accessible via the web, developed in **Articulate Storyline** and hosted on GitHub Pages.

---

## Educational Objectives
- Explain the fundamental steps in semiconductor manufacturing (e.g., wafer preparation, photolithography, etching, deposition).  
- Familiarize learners with the terminology and concepts involved in IC fabrication.  
- Provide an interactive, visually rich learning experience for foundational electronics education.

---

## Content Outline
The module covers the following stages in IC fabrication:
1. **From Silicon Ingot to Wafer:** Crystal growth, slicing, and polishing.  
2. **Layering & Patterning:** Photolithography, masking, and etching processes.  
3. **Doping & Diffusion:** Creating p-type and n-type regions for semiconductor functionality.  
4. **Metallization & Interconnection:** Establishing conductive pathways.  
5. **Packaging:** Final assembly and chip protection.
